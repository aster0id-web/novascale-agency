# NovaScale Studio — Agency Landing Page & Project Estimator

**[View Live Demo →](https://novascale-agency-three.vercel.app/)**

![NovaScale Studio Preview](./public/preview.png)

A high-converting agency landing page built with a crisp editorial design system, fast page loads, and interactive client intake tools.

> **Note:** This is a concept portfolio project built to demonstrate modern frontend engineering, UI/UX design systems, and live form integration.

## Key Features

- **Interactive Project Cost & Timeline Calculator:** Dynamically estimates project pricing and delivery timelines in real time based on project type and selected add-ons, then pre-fills the inquiry form.
- **Filterable Case Studies:** Category-filtered project showcase with concrete business outcome metrics and detailed modal views.
- **Live Email Intake Form:** Validated client inquiry form connected to Web3Forms for instant email delivery, paired with one-click copy-to-clipboard email links.

## Tech Stack

- **Framework:** Next.js (App Router) & React
- **Language:** TypeScript
- **Styling & Fonts:** Tailwind CSS v4, `next/font/google` (Bricolage Grotesque & DM Sans)
- **Icons & Motion:** Lucide React, Framer Motion
- **Form Delivery & Hosting:** Web3Forms, Vercel
